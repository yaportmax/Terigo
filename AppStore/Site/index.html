Terigo

Organize Strava routes.

Terigo is a focused iPhone route library for importing Strava routes, organizing hundreds of saved routes, browsing them on a map, and following them with route-aware tracking.

What It Does

Route library Stackable filters Map browse Lists + sharing 3D maps Live tracking

Import saved Strava routes, search and filter them quickly, organize them with lists and tags, browse by starting location, and launch route-aware live tracking from the same app.
