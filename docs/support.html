Terigo Support

Use the links below for support, App Review follow-up, and bug reports.

Support Channels

  • Support page: https://yaportmax.github.io/Terigo/support.html
  • Issue tracker: https://github.com/yaportmax/Terigo/issues
  • Response target: 2 business days

When Reporting an Issue

  • Device model
  • iOS version
  • Terigo version
  • Whether the issue happened during Strava connect, route sync, activity sync or upload, route tracking, GPX import, list sharing, map browsing, or offline download
